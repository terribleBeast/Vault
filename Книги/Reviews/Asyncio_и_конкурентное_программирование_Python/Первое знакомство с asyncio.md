Библиотека Asyncio впервые появилась в Python 3.4 (Один из разработчиков [Юрий Селиванов](obsidian://open?vault=%D0%9D%D0%B0%D1%87%D0%B0%D0%BB%D0%BE%20%D0%BF%D1%83%D1%82%D0%B8&file=%D0%92%D0%B8%D0%B4%D0%B5%D0%BE%2FPython)).
