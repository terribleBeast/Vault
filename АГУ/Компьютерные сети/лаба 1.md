1) откройте командную строку на Вашем компьютере;  
2) введите команду ipconfig, затем ipconfig -all, опишите в чем различие результатов?  
   `ipconfig` - утилита командной строки для вывода деталей текущего соединения и управления клиентскими сервисами DHCP и DNS.
   Ключ `-all` - отображает полную информацию по всем адаптерам.

3) постройте ARP таблицу, используя команду arp -a; 
   **ARP** (от англ. Address Resolution Protocol — протокол определения адреса) — протокол в компьютерных сетях, предназначенный для определения MAC-адреса другого компьютера по известному IP-адресу.
4) выполните ping для 3 ресурсов, значительно удаленных друг от друга ( к примеру, ping ресурса Австралии, России, Японии). Исходя из результатов, опишите, что влияет на пинг.  Подумайте и напишите, какие еще показатели могут влиять на пинг.  
5) для ресурсов в пункте 4, выполните tracert;  
6) введите (в командной строке) nslookup ya.ru, подумайте и напишите - для чего предназначена данная утилита;  
7) с помощью утилиты nslookup определите, кому принадлежит  8.8.8.8.
