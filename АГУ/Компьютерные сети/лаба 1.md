### 3. Постройте ARP таблицу, используя команду `arp -a`; 
   **ARP** (от англ. Address Resolution Protocol — протокол определения адреса) — протокол в компьютерных сетях, предназначенный для определения MAC-адреса другого компьютера по известному IP-адресу.
   **Таблица ARP** — это **таблица соответствия адресов IP и MAC в компьютерных сетях**. Она хранится в памяти операционной системы и содержит записи для каждого известного ей узла сети.
   **Назначение таблицы ARP** — записывать найденные пары MAC и IP адресов устройств, подключённых к сети. Каждое устройство, подключённое к сети, имеет свою таблицу ARP, которая отвечает за хранение пар адресов, с которыми взаимодействовало конкретное устройство.
   Если в таблице нет записи, источник отправляет широковещательный запрос ARP всем устройствам в сети. Когда IP-адреса устройств совпадают, оно отправляет ответ, который затем обновляется в таблице ARP.
   
   Вывод команды `arp -a`.

### 4. Выполните `ping` для 3 ресурсов, значительно удаленных друг от друга (к примеру, ping ресурса Австралии, России, Японии). Исходя из результатов, опишите, что влияет на пинг.  Подумайте и напишите, какие еще показатели могут влиять на пинг.  

`ping` – утилита командной строки, которая нужна для проверки подключения к другому компьютеру на уровне IP. Утилита отправляет 4 пакета (по умолчанию) и считает время, которое потребовалось для отправки и получения ответа.

Факторы влияющие на пинг:
1) Расстояние между устройствами
2) Состояние инфраструктуры.
3) Количество прокси (прыжков).
4) Загруженность сети
5) Тип соединения
6) Тип протокола (TCP или UDP)
7) Размер пакетов

Выполнение команды для ресурсов в:
• Австралии ([www.abc.net.au](https://www.abc.net.au/ "https://www.abc.net.au/"))
• России ([yandex.ru](https://yandex.ru/ "https://yandex.ru/"))  
• Японии ([www.ntt.co.jp](https://www.ntt.co.jp/ "https://www.ntt.co.jp/"))
