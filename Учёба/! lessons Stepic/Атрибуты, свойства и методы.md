## Атрибуты: 
#### `__dict__` 
В нем хранятся все атрибуты класса. Поиск атрибуты происходит сначала в словаре экземпляра, затем класса.

#### Функции, работающие с атрибутами

`getattr()`
`setattr()`
`delattr()` если нет, то `AtributeError`
`hasattr()`

### Методы

  Параметр `self` часто называют **контекстным объектом**.
  Метод `__init__()` называют **методом инициализации** или **инициализатором**. (всегда должен возвращать None)
  `__new__()` - конструктор
  
1. `__init__` is called with an already built up instance of the object as first parameter (normally called `self`, but that's just a parameter name).
2. `__new__` instead is called passing the **class** as first parameter and is expected to return an instance (that will be later passed to `__init__`).
3. This allows for example `__new__` to return an already-existent instance for value-based objects that are immutable and for which identity shouldn't play a role.


Because `__new__()` and `__init__()` work together in constructing objects (`__new__()` to create it, and `__init__()` to customize it), no non-`None` value may be returned by `__init__()`; doing so will cause a `TypeError` to be raised at runtime.
